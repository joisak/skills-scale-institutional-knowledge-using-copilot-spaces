# OctoAcme — Release Readiness Checklist

Use this checklist before every release to ensure preparation and accountability across all roles.

## Pre-release
- [ ] All acceptance criteria met
- [ ] All PRs reviewed, merged, and pass CI
- [ ] Regression and smoke tests complete
- [ ] Release notes drafted and approved
- [ ] Rollback plan up to date
- [ ] Stakeholder notification plan confirmed

## Release
- [ ] Release window scheduled/communicated as needed
- [ ] Backup or snapshot created if applicable
- [ ] Deploy staged to production
- [ ] Monitor key dashboards for early signals
- [ ] Communication sent to all required partners

## Post-release
- [ ] Post-release verification run
- [ ] Action items (if any) documented
- [ ] Retrospective scheduled if major news/issues
- [ ] Update documentation/process artifacts as needed

---

**Roles Involved:**
- Release Manager (drives checklist)
- Developers (verify and fix issues)
- QA (confirms test status)
- Project Manager (coordinates logs/docs and comms)
- Stakeholder Champion (ensures comms loop is closed)
